em_from_state

pyR2D2.synth.euv.em_from_state(data, n, los='x', logte_edges=array([5., 5.05, 5.1, 5.15, 5.2, 5.25, 5.3, 5.35, 5.4, 5.45, 5.5, 5.55, 5.6, 5.65, 5.7, 5.75, 5.8, 5.85, 5.9, 5.95, 6., 6.05, 6.1, 6.15, 6.2, 6.25, 6.3, 6.35, 6.4, 6.45, 6.5, 6.55, 6.6, 6.65, 6.7, 6.75, 6.8, 6.85, 6.9, 6.95, 7., 7.05, 7.1, 7.15, 7.2, 7.25, 7.3, 7.35, 7.4, 7.45, 7.5, 7.55, 7.6, 7.65, 7.7, 7.75, 7.8, 7.85, 7.9, 7.95, 8.]))[source]

3D 出力 (remap/qq) から箱ごとの EM を作り直す (R2D2plus の vl_dem.dac と同じ定義)。

n_e と T は EOS 表 (ρ, s) から引く (表と線形の合成はしない。R2D2plus と同じ)。 表に ne が要る (data.p.read_eos_table が読んだ表に ne があると log_ne_e ができる)。 箱の外の温度は数えない。セルの幅は margin 込みの座標 (p.xg・yg・zg) の 中心差分 0.5 (c[i+1] - c[i-1]) で、物理セルの両端も同じ (R2D2plus の write_hist_dem と同じ)。

Parameters:

  • data (pyR2D2.Data)

  • n (int) – 3D 出力の番号 (nd。vl の番号 nd_vl とは違うことがある)

  • los ({"x", "y", "z"}) – 視線の向き (pyR2D2 の軸、x が鉛直)。戻り値の形は x: (jx, kx, nbin)、y: (ix, kx, nbin)、 z: (ix, jx, nbin) で、pyR2D2.OnTheFly.read_dem() の em_x・em_y・em_z と同じ

  • logte_edges (array) – 箱の境界 (等間隔でなくてよい)

Return type:

numpy.ndarray (float64)
