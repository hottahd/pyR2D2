Data

class pyR2D2.Data(datadir, verbose=False, self_old=None)[source]

Bases: object

Class for managing R2D2 data

Variables:

  • p (pyR2D2.Parameters) – Run parameters and grids (x, y, z, nx, ...); also reachable directly as d.x, d.nx, … (attribute lookup falls through to d.p).

  • qf (pyR2D2.FullData) – Full 3D data (remap/qq). d.qf.read(n) -> d.qf.ro, vx, vy, vz, bx, by, bz, se, pr, te, op

  • qx (pyR2D2.XSelect) – 2D plane at a given x. d.qx.read(xs, n) -> d.qx.ro, vx, vy, vz, bx, by, bz, se, ...

  • qz (pyR2D2.ZSelect) – 2D plane at a given z. d.qz.read(zs, n) -> d.qz.ro, vx, ...

  • qm (pyR2D2.MPIRegion) – 3D data of one remap MPI region. d.qm.read(ixrt, n) -> d.qm.ro, ...

  • qr (pyR2D2.RestrictedData) – 3D data inside a sub-volume. d.qr.read(n, keys, x0=..., x1=..., ...) -> d.qr.ro, ...

  • qt (pyR2D2.OpticalDepth) – 2D data on optical-depth surfaces (tau = 1, 0.1, 0.01). d.qt.read(n) -> d.qt.rt, he, fr, ro, se, vx, ... (rt at tau=1, rt01 at 0.1, rt001 at 0.01; multigroup rt1, rt2, ...)

  • vc (pyR2D2.OnTheFly) – On-the-fly means, RMS, correlations and xy/xz cuts (remap/vl). d.vc.read(n) -> d.vc.rom, sem, serms, se_xz, bx_xy, ... (n は nd_vl の番号。出力の間隔が 4 つでないランでは nd と同じ); d.vc.read_et(n) -> d.vc.etm (R2D2plus only)

  • qs (pyR2D2.Slice) – 2D slice output (slice/). d.qs.read(n_slice, direc, n) -> d.qs.ro, vx, ..., pr, te (n は nd_slice の番号。出力の間隔が 4 つでないランでは nd_tau と同じ)

  • q2 (pyR2D2.TwoDimension) – Full data of a 2D run (dict access). d.q2.read(n) -> d.q2['ro'], d.q2['tu'], ...

  • ms (pyR2D2.ModelS) – Model S based stratification. d.ms.read()

  • qa (qp,) – Checkpoint before / after step n. d.qp.read(n, n_prev), d.qa.read(n, n_aftr)

  • time (float) – Time at a selected step. See pyR2D2.Data.time_read()

  • qc (numpy.ndarray, float) – 3D checkpoint data. See pyR2D2.Data.qc_read()

  • sync (pyR2D2.Sync)

  • eos (pyR2D2.cpp_util.EOS)

  • yinyang (pyR2D2.cpp_util.YinYang)

  • appear. (help(d.qt) (or d.qt? in IPython) shows how to read and which variables)

time_read(n, tau=False, verbose=True, use_zip=False, kind=None)[source]

Reads time at a selected time step The data is stored in self.t

Parameters:

  • n (int) – selected time step for data

  • tau (bool) – if True time for optical depth (high cadence). Same as kind="tau"

  • verbose (bool) – if True, print a message indicating that the time variable has been stored in self.time

  • use_zip (bool) – if True, read time from time.zip instead of the original files if False, read from the original file if it exists; otherwise, fall back to time.zip.

  • kind (str, optional) – "mhd" (or "qq", 3D, number nd), "vl" (nd_vl), "tau" (nd_tau) or "slice" (nd_slice). Runs with one output interval per family (R2D2plus output_cadence = 2) keep the time of each in time/<kind>; older runs use time/mhd for vl and time/tau for slice.

Returns:

time – time at a selected time step

Return type:

float

zip_time(remove_original=False)[source]

Parameters:
