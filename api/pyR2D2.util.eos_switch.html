eos_switch

pyR2D2.util.eos_switch(data, ro1, se1, var, ct0=0.003)[source]

Returns the equation of state as R2D2 itself evaluates it, i.e. with the switch between the table EOS and the linearized EOS.

Why this exists

pyR2D2.util.eos(), pyR2D2.util.eos_table() and pyR2D2.Data.eos.eval all read the table unconditionally. R2D2 does not. Wherever the code needs pressure, temperature or internal energy it computes the relative amplitude

\[c_t = \max(|\rho_1|/\rho_0, |s_1|/s_0)\]

and uses the linearized EOS when \(c_t \le c_{t0}\) (ct0 = 3e-3, eos_def.F90), falling back to the table only above it. The switch is hard, not smooth:

feos = sign(0.5, ct - ct0) + 0.5

and appears identically in runge_kutta_cartesian.F90 / runge_kutta_spherical.F90 (pressure), artdif_cartesian.F90 / artdif_spherical.F90 (temperature and enthalpy), cfl.F90 (dprdro, hence the sound speed) and remap_calc.F90 (the pr/te/en written into remap/vl).

In a deep-convection run \(c_t\) never reaches \(c_{t0}\), so the code runs entirely on the linearized EOS while a plain table lookup returns something else. That is the discrepancy this function removes.

param data:

Instance of pyR2D2.Data or pyR2D2.Read classes

type data:

pyR2D2.Data, or, pyR2D2.Read

param ro1:

Density perturbation, i.e. d.qq['ro'] as stored in the output. The first axis must be the vertical one (size ix).

type ro1:

numpy.ndarray

param se1:

Entropy perturbation, same shape as ro1

type se1:

numpy.ndarray

param var:

Variable name; pr, te, en, op, or dprdro

type var:

str

param ct0:

Switching threshold, eos_def.F90’s ct0. Change it only to experiment; the code itself compiles it in as 3e-3.

type ct0:

float

returns:

qq – For pr, te and en: the perturbation, matching what remap_calc.F90 writes into the output files (add d.p.pr0 etc. for the total). For op and dprdro: the value itself, since neither has a linearized perturbation form. op is never switched (the table is the only source); dprdro switches to the background profile d.p.dprdro.

rtype:

numpy.ndarray
