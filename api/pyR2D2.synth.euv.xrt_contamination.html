xrt_contamination

pyR2D2.synth.euv.xrt_contamination(ssw_dir, channel, date)[source]

XRT の汚染 (DEHP) の厚さ [Å] (CCD、焦点面フィルター) を SSW xrt_time2contam と同じく作る。

contam/xrt_contam_on_ccd.geny と contam/xrt_contam_on_filter.geny を時刻で線形に補間し、 四捨五入する。データの最後の時刻より後は作れない (ValueError)。
