ResponseTable

class pyR2D2.synth.euv.ResponseTable(logt, responses, units='DN cm^5 s^-1 pix^-1', meta=None)[source]

Bases: object

温度応答の表 R(log10 T) をチャンネルごとに持つ。

Parameters:

  • logt (array (n,)) – log10 T [K] (増加順)

  • responses (dict of str to array (n,)) – チャンネル名 → 応答 (単位は units)

  • units (str) – 応答の単位。既定は "DN cm^5 s^-1 pix^-1"

  • meta (dict, optional) – 出どころなどの記録 (保存すると表の頭に JSON で残る)

  • (テキスト):: (表の形式) – # pyR2D2-response-table 1 # units: DN cm^5 s^-1 pix^-1 # meta: {“source”: …, …} # logT A94 A131 … 5.00 1.2e-28 …

  • も読める。 (# 以外の行は空白区切りの数。.npz (キー logt と各チャンネル、任意で units・meta))
