xrt_response_from_ssw

pyR2D2.synth.euv.xrt_response_from_ssw(ssw_dir, channels=('Al-mesh', 'Al-poly', 'C-poly', 'Ti-poly', 'Be-thin', 'Be-med', 'Al-med', 'Al-thick', 'Be-thick'), date=None, contam_thick=None, emiss_file='XRT_emiss_model.default_CHIANTI_20240306.geny', channels_file='xrt_channels_v0017.geny', port='R')[source]

XRT の温度応答を SSW の公開ファイルから作る (make_xrt_temp_resp(make_xrt_wave_resp(contam_time=date), /chianti_default) と同じ手順)。

要るファイル (ssw_dir か、その channels/・emiss/・contam/ に置く。 SSW_XRT_URL から取れる):

channels/xrt_channels_v0017.geny         各チャンネルの透過率・鏡・CCD
emiss/XRT_emiss_model.default_CHIANTI_20240306.geny   CHIANTI 10 (コロナの組成) のスペクトル
contam/xrt_contam_on_ccd.geny, contam/xrt_contam_on_filter.geny, contam/n_DEHP.txt   汚染

手順 (SSW の make_xrt_ea・make_xrt_sr・make_xrt_contam・multifilt・make_xrt_temp_resp):

  1. 汚染の厚さ: date から (xrt_contamination())、または contam_thick = (CCD, フィルター) [Å]

  2. 有効面積 = 透過率 × DEHP(CCD) × DEHP(フィルター) × 開口面積

  3. 分光応答 = 有効面積 × (hc/λ) × (画素 / 焦点距離)² / 3.65 eV / gain (既定は R 側の読み出し)

  4. R(T) = Σ_λ スペクトル(λ, T) × 分光応答(λ) × Δλ

IDL は分光応答をスペクトルの波長へ 2 次で補間する (interpol, /quad) が、ここは線形。

Return type:

ResponseTable
