trace_field_line

pyR2D2.cpp_util.trace_field_line(x: Annotated[numpy.typing.ArrayLike, numpy.float64], y: Annotated[numpy.typing.ArrayLike, numpy.float64], z: Annotated[numpy.typing.ArrayLike, numpy.float64], bx: Annotated[numpy.typing.ArrayLike, numpy.float32], by: Annotated[numpy.typing.ArrayLike, numpy.float32], bz: Annotated[numpy.typing.ArrayLike, numpy.float32], fields: dict, x0: SupportsFloat | SupportsIndex, y0: SupportsFloat | SupportsIndex, z0: SupportsFloat | SupportsIndex, ds: SupportsFloat | SupportsIndex, n_steps: SupportsInt | SupportsIndex, sign: SupportsFloat | SupportsIndex = 1.0, method: str = 'implicit_midpoint', max_iter: SupportsInt | SupportsIndex = 20, tol: SupportsFloat | SupportsIndex = 1e-10) → dict

Trace a field line through a 3D magnetic field. :param x: 1D coordinate arrays. Must be uniform (checked, with an error rather

than silent corruption). Read as float64; positions are integrated in double as offsets from x[0], y[0], z[0], so a large absolute offset no longer eats into the precision.

Parameters:

  • y (numpy.ndarray) – 1D coordinate arrays. Must be uniform (checked, with an error rather than silent corruption). Read as float64; positions are integrated in double as offsets from x[0], y[0], z[0], so a large absolute offset no longer eats into the precision.

  • z (numpy.ndarray) – 1D coordinate arrays. Must be uniform (checked, with an error rather than silent corruption). Read as float64; positions are integrated in double as offsets from x[0], y[0], z[0], so a large absolute offset no longer eats into the precision.

  • bx (numpy.ndarray) – 3D magnetic field components.

  • by (numpy.ndarray) – 3D magnetic field components.

  • bz (numpy.ndarray) – 3D magnetic field components.

  • fields (dict) – Extra 3D arrays to interpolate along the line.

  • x0 (double) – Starting point, in the same absolute coordinates as x, y, z.

  • y0 (double) – Starting point, in the same absolute coordinates as x, y, z.

  • z0 (double) – Starting point, in the same absolute coordinates as x, y, z.

  • ds (double) – Arc-length step.

  • n_steps (int) – Maximum number of points.

  • sign (double, optional) – +1 traces along B, -1 against it. Default +1.

  • method (str, optional) – ‘implicit_midpoint’ (default) is time symmetric, so tracing back with -ds retraces the same points to tolerance. ‘explicit_midpoint’ is the pre-2026-08-23 behaviour, kept for comparison.

  • max_iter (int, optional) – Fixed-point iterations allowed per step for the implicit scheme.

  • tol (double, optional) – Convergence tolerance, relative to ds.

Returns:

‘x’, ‘y’, ‘z’ : float64 positions, truncated at n_valid each key of fields : float32 values along the line ‘n_valid’ : number of points produced ‘status’ : 0 ran out of steps, 1 left the domain, 2 |B| vanished,

3 iteration did not converge

Return type:

dict
